# Skill ideas for the hands-on part

Pick one. Use `skill-builder`. Bring one real (or fake) example.

| Idea | Input | Output |
|---|---|---|
| Quote from brief | client brief text | quote HTML and PDF, using `rates.csv` |
| Client onboarding | new client name | welcome email plus checklist of what you need from them |
| Expense sorter | list of receipts | categories, VAT you can reclaim, questions |
| Weekly plan | calendar, open invoices, next steps | plan for Friday admin and next week |
| Brand voice check | any text | rewrite in `brand-voice.md` style, list of changes |
| Market research brief | niche, 3 competitor sites | one page: who, price, gaps |
| Tax prep checklist | invoices log, quarter | what to collect for your accountant |
| Testimonial request | finished project | short email asking for a quote |
| Meeting prep | client name | one page: history, open points, questions to ask |
