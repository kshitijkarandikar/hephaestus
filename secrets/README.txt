This folder holds your Google sign-in files. Nothing else belongs here.

  google-client.json   the app file from Google. Saved here by:
                       ./kit google client file=<the file you downloaded>
  google-token.json    your sign-in. Made by: ./kit google auth

Rules:
- Never share, email, upload or commit these files. Git ignores this folder.
- The AI assistant is not allowed to open, list or move anything in here.
  You do not have to put files here by hand. Tell the AI where your downloaded
  file is, and the kit saves it here for you.
- To sign out: ./kit google logout (run it yourself in a normal terminal).
- This README is the only file in this folder that is stored in git.
